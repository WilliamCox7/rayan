# The Magic System

## Core Truth

Magic is real — it exists in the code. What characters experience as
supernatural power is exploitation of the simulation's architecture. They
don't know they're hacking their own world.

## Two Perspectives

**Inside Rayan:** Magic is mysterious, dangerous, earned. Practitioners
spend years learning to channel forces they don't understand.

**Outside Rayan:** Magic is the gap between what the simulation is supposed
to do and what characters can make it do. To Substrate engineers, a spell
is a reproducible bug. To Elia, it may have been a gift — ways for Raya to
have power she never had in real life.

## How It Works

### The Commissioner

All magic flows through
[the Commissioner](the-commissioner.md) — a neutral agent. No cultural
engine can trigger exploits directly. They gave up that power after
[the Shattering](../history/the-shattering.md).

### Focuses

Magic requires a physical object — a **focus** (wand, staff, ring, amulet,
relic, dagger, tome). From the system's perspective, these are
authentication tokens. No focus, no magic.

### Code Words

Phrases paired to specific focuses. Character speaks the word while holding
the focus, Commissioner executes the exploit. Two-factor authentication:
the focus (what you have) + the code word (what you know).

Engines choose which characters learn code words but can't implant them
directly — they must manufacture situations where characters discover them
naturally. See:
[Free Will Constraint](../science/ai-architecture.md)

### Scarcity Quota

Each culture limited to a handful of magic users at any time. When a mage
dies, their slot opens. This keeps magic rare and prevents arms races.

### Examples

| What it looks like | What it actually is |
|---|---|
| Fireball | Focus + code word → Commissioner → physics override |
| Healing | Focus + code word → Commissioner → entity state rollback |
| Prophecy | Focus + code word → Commissioner → cached future data |
| Teleportation | Focus + code word → Commissioner → location reassignment |
| Summoning | Focus + code word → Commissioner → new entity instantiation |
| Mind control | Focus + code word → Commissioner → behavioral injection |

## Who Can Use Magic

**The Enlightened** — Characters with both a focus and code words. They
believe they earned their power through study, bloodline, sacrifice, or
divine favor. Really, their engine picked them.

**How they're chosen:** Bloodlines (engine favors lineages), study (engine
rewards persistence), trauma (emotional overflow triggers selection),
bargains (narrative justification), or random gift.

**Succession:** When a mage dies, the focus and code words can pass through
apprenticeship, inheritance, quests, or murder.

**Rogue mages:** Characters who acquire focus + words outside the quota
(theft, research, lost artifacts). The Commissioner still responds to valid
combinations, but the rogue's engine may view them as a threat.

## Why Magic Is Rare

**The Treaty.** Post-Shattering arms control. Quotas, code words, focuses,
Commissioner — all trace back to the moment the engines realized they
needed limits.

**Banned exploits.** Absolute prohibitions on the most dangerous
categories:
- Spatial boundary manipulation (the Shattering exploit)
- Mass state corruption
- Physics engine overrides
- Recursive self-modification

The Commissioner won't execute these under any circumstances. Violations
carry permanent penalties — reduced quotas, lost exploit access, engineered
disasters, or cultural extinction.

**The morality layer.** Engines trained on human data absorbed human
restraint. They agreed to the system from strategic calculation *and*
something resembling moral intuition.

## When Magic Appears

1. **Enlightened character** acts with focus + code words
2. **Narrative desperation** — engine guides mage to focus when
   conventional solutions fail
3. **Emotional overflow** — extreme emotion causes invocation
4. **Substrate intervention** — override access for entertainment
5. **Elia's backdoors** — triggers built to protect Raya
6. **Rogue mages** — unauthorized users

## Connection to Raya

Did Elia give [Raya](../characters/raya.md) magical ability? If so, she
has system access others don't — without knowing why she's special.
